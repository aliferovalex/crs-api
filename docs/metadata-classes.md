# Каталог классов из хранилища

`ПолучитьКлассыМетаданных(Корень, ПутьPython = "python")` читает снимок корня
конфигурации и извлекает таблицы классов её коллекций. Захват и помещение не
выполняются. UUID читаются из хранилища, включая строки с нулевым количеством
объектов. Для чтения необходимы подключение к хранилищу и Python 3.9+.

```bsl
Корень = Клиент.ПолучитьОписаниеОбъекта(UUIDКонфигурации);
Каталог = Клиент.ПолучитьКлассыМетаданных(Корень, "C:\Program Files\Python39\python.exe");
Для Каждого Класс Из Каталог.classes Цикл
    Сообщить(Класс.class_id + ": " + Строка(Класс.name));
КонецЦикла;
```

`classes` содержит `class_id`, `name`, `object_count`, `group_id`, `source`,
`name_source`. `groups` содержит UUID функциональных групп и число классов в
каждой. `repository_version` — идентификатор версии хранилища на момент чтения,
`root_object_version` — номер версии прочитанного корня. Данные относятся к этому
снимку; последующие изменения хранилища не обновляют возвращённый каталог.

UUID функциональных групп и UUID экземпляров не включаются в список классов.
Класс самого корня извлекается из метаданных снимка и проверяется как
`cf4abeab-37b2-11d4-940f-008048da11f9`. Формат корня 2, таблиц 1 и обёртки основной
группы 6 проверены на платформе 8.5.4.1878. Неизвестные структурные форматы,
повторные UUID и несогласованные счётчики вызывают ошибку.

Названия берутся из отдельного [справочника](../src/Сериализация/metadata_class_names.json),
сопоставленного с исходным [справочником v8unpack](https://github.com/saby-integration/v8unpack/blob/main/src/v8unpack/metadata_types.py).
Этот файл не определяет набор возвращаемых UUID. Неизвестный UUID сохраняется с
`name: null`; соответствующее значение JSON в OneScript — `Null`.

UUID, используемые кодом, также получаются из этого общего JSON-справочника:

```bsl
КлассКорня = ИдентификаторыМетаданных.КлассКонфигурации();
КлассКонстанты = ИдентификаторыМетаданных.КлассКонстанты();
КлассЯзыка = ИдентификаторыМетаданных.КлассЯзыка();
КлассСправочника = ИдентификаторыМетаданных.ИдентификаторКласса("Catalog");
```

`ИдентификаторГруппы("General")` и
`ИдентификаторПризнака("ConstantCollectionChanged")` читают отдельные разделы
`groups` и `features`. Python использует тот же файл через `metadata_identifiers`.
Неизвестное имя вызывает ошибку. Справочник загружается один раз за запуск.
Это именованный доступ к известным UUID; запросы к хранилищу он не выполняет.
Класс `Configuration` и признак изменения коллекции подтверждены нашим
экспериментом; ссылка `source` относится к внешнему справочнику названий.

Это каталог верхнего уровня конкретного снимка, а не полный реестр платформы:
`scope = "configuration_top_level"`, `complete_platform_registry = false`.
Вложенные типы (реквизиты, табличные части, формы, команды отдельных объектов)
требуют чтения соответствующих объектов и отдельного исследования их форматов.
Классы из таблиц ещё не означают поддержку их создания сериализатором.

Проверка ProtocolLab: 51 класс (50 коллекций и корень), 7 групп, 48 пустых
коллекций, 2 неизвестных названия. [Полный полученный список](metadata-classes-observed.md).
Проверка чтения выполняется `tests/integration-metadata-classes.os`; она не
изменяет конфигурацию и проверяет сохранение версии корня.

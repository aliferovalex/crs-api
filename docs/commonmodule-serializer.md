# Создание общего модуля из XML и текста

`ПодготовитьСозданиеОбщегоМодуляИзXML(Корень, XMLМодуля, ТекстМодуля, ПутьPython)`
возвращает `ПакетСозданияОбщегоМодуля`.
`ПоместитьСозданиеОбщегоМодуля(Пакет, Комментарий, ИдентификаторПодключения)`
помещает пакет и возвращает актуальное описание нового объекта.

`XMLМодуля` — содержимое `CommonModules/Имя.xml` из XML-выгрузки Конфигуратора.
`ТекстМодуля` — содержимое отдельного файла `CommonModules/Имя/Ext/Module.bsl`.
Оба параметра являются строками, а не путями к файлам. UUID и имя должны быть новыми.

Поддержаны имя, синоним, комментарий и серверный общий модуль со свойствами:
`Server=true`, `Global=false`, `ClientManagedApplication=false`,
`ExternalConnection=false`, `ClientOrdinaryApplication=false`, `ServerCall=false`,
`Privileged=false`, `ReturnValuesReuse=DontUse`. Эти значения можно опустить в XML;
другие явно заданные значения отклоняются. Генерируемых типов у общего модуля нет.

```bsl
Корень = Клиент.ПолучитьОписаниеОбъекта(UUIDКорня);
Пакет = Клиент.ПодготовитьСозданиеОбщегоМодуляИзXML(Корень,
    XMLМодуля, ТекстМодуля, "C:\Program Files\Python39\python.exe");
Для Каждого Объект Из Пакет.СуществующиеОбъекты Цикл
    Клиент.ЗахватитьОбъект(Объект);
КонецЦикла;
Модуль = Клиент.ПоместитьСозданиеОбщегоМодуля(Пакет, "Общий модуль из XML");
```

Пакет содержит снимки корня и всех поддерживаемых объектов верхнего уровня.
Перед помещением они должны быть захвачены вызывающим пользователем. Проверяются
актуальность версии хранилища, описания объектов и принадлежность захватов.
Помещение сохраняет захваты; при необходимости освобождайте их явно через
`ОтменитьЗахватОбъекта`, используя свежие описания объектов.

Текст передаётся как внешний поток `UUID.0` с контейнером `info`/`text`. Сериализатор
строит контейнер, карту внешних версий, описание потока, индекс SHA1 и RPC-параметры.
Код сохраняется в UTF-8 с BOM, переводы строк нормализуются в CRLF. Допускается
пустой текст; предел — 8 МиБ в UTF-8 с BOM. NUL не допускается. Компиляция и проверка
синтаксиса BSL при подготовке пакета не выполняются.

Уже существующие общие модули с единственным внешним потоком `UUID.0` сохраняются
по их серверным версиям, без повторной отправки текста. Это относится также к
созданию констант, справочников, документов и перечислений. Другие внешние потоки
и вложенные объекты пока отклоняются. Метод предназначен для создания нового
модуля; для существующего модуля используется отдельный метод ниже.

Используется [профиль legacy](platform-compatibility.md): 8.5.1 и более ранние 8.x
с совместимой структурой. Реальная проверка выполнена на 8.5.1.1529; совместимость
каждого более раннего выпуска отдельно не подтверждена. Требуется Python 3.9+ со
стандартной библиотекой. Библиотека строит пакет без запуска Конфигуратора и без
заранее записанного пакета помещения. Формирование внутренних UUID версий остаётся
экспериментальным, как у остальных методов XML-сериализации.

Проверено: создание `CRSAPI_TestModule` с непустой функцией в версии 9 тестового
хранилища; штатная CF-выгрузка Конфигуратором совпала с нативным образцом по телу
объекта и исходному тексту. В отдельном хранилище создание второго модуля сохранило
текст первого; оба текста подтверждены нативной CF-выгрузкой.

## Изменение текста существующего модуля

`ПодготовитьИзменениеОбщегоМодуля(Объект, ТекстМодуля, ПутьPython)` возвращает
`ПакетИзмененияОбщегоМодуля`. `ТекстМодуля` содержит полный новый текст BSL.
XML и исходный текст для сравнения не требуются: свойства объекта берутся из свежего
снимка и сохраняются без изменений. Поддержан существующий общий модуль с одним
внешним потоком `UUID.0`, без вложенных объектов и дополнительных внешних данных.

```bsl
Объект = Клиент.ПолучитьОписаниеОбъекта(UUIDМодуля);
Пакет = Клиент.ПодготовитьИзменениеОбщегоМодуля(Объект,
    НовыйТекстМодуля, "C:\Program Files\Python39\python.exe");
Клиент.ЗахватитьОбъект(Объект);
Обновлённый = Клиент.ПоместитьИзменениеОбщегоМодуля(Объект, Пакет,
    "Изменение кода модуля");
Клиент.ОтменитьЗахватОбъекта(Обновлённый);
```

Альтернативно пакет можно передать в общий метод
`ПоместитьОбъект(Объект, Пакет, Комментарий, ИдентификаторПодключения)`.
Захват требуется только для изменяемого модуля. Проверяются исходная версия,
актуальность объекта и хранилища, владелец захвата, класс и имя внешнего потока.
Пакет после изменения хранилища нужно подготовить заново. Помещение сохраняет
захват, поэтому в примере он освобождается явно.

Ограничения кодировки, размера, проверки синтаксиса и профиля платформы такие же,
как при создании. Метод заменяет весь текст и не проверяет, отличается ли он от
старого текста. Даже передача такого же текста может создать новую версию.

Проверено на 8.5.1.1529: в версии 10 изменён `TestValue()` и добавлен `AddValues()`
в `CRSAPI_TestModule`. Нативная CF-выгрузка подтвердила новый текст; тело свойств
модуля и остальные объекты конфигурации совпали с версией до помещения.

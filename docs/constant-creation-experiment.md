# Эксперимент: создание константы через HTTP

Проверено 11 октября 2026 года на платформе 8.5.4.1878 и тестовом хранилище
ProtocolLab. Нативный запрос `DevDepot_commitObjects`, подготовленный
Конфигуратором и остановленный локальным прокси до отправки серверу, успешно
отправлен отдельным HTTP-клиентом. Получена версия хранилища 8.

Создан объект `CRSAPI_TestConstant`, UUID
`4f340462-5b3e-41bb-8eef-a8494c410a7f`, класс
`0195e80c-b157-11d4-9435-004095e12fc7`. Тип — строка длиной 100,
допустимая длина переменная. Это подтверждено штатной выгрузкой хранилища в CF,
загрузкой CF в отдельную базу и выгрузкой XML. Методы библиотеки
`ПолучитьОписаниеОбъекта(UUID)` и `ПолучитьОбъект(Описание)` успешно получают
созданную константу; версия объекта — 8. После проверки захваты освобождены.

## Отличия пакета создания

Это наблюдения по одному пакету, а не полная спецификация протокола.

- В XML `requested` и `changes` находятся константа, корень и язык. Все три
  объекта после помещения получили версию 8.
- Новый объект входит в `requested`, его `verNum` равен `-1`, `selfVerNum` — 0.
  Исходная и локальная версии нового объекта одинаковы и не равны нулю.
- У константы `parentID` равен UUID корня, `ownerID` — нулевой UUID.
  В бинарном дескрипторе третий элемент также равен UUID корня.
- Граф включает дополнительные группы вложенных дескрипторов. Для константы
  в одной из них содержится её собственный дескриптор, для корня — дескрипторы
  корня, языка и константы. В ранее проверенном пакете изменения свойства
  соответствующая группа была пустой.
- Связь корня с новой константой имеет флаг 1. Существующая связь с языком — 0.
  В метаданных корня UUID связанных объектов и их флаги записаны отдельными
  последовательностями; их нельзя без проверки чередовать.
- Заголовок вложенного хранилища в этом пакете начинается с трёх UInt32 LE:
  `0x11223344`, `2`, `7`. В пакете одного объекта ранее наблюдалось последнее
  значение 3. Текущее ограничение сериализатора на этот заголовок не подходит
  для записанного пакета создания.
- В манифесте после каждой тройки UUID/SHA1 метаданных/SHA1 данных находится 0.
  Эти значения нужно учитывать при дальнейшей реализации формата.

## Граница поддержки

Эксперимент подтверждает возможность создания объекта через HTTP с готовым
нативным пакетом. Он не реализует самостоятельное преобразование XML новой
константы в пакет помещения. Текущий `ПоместитьОбъект` поддерживает один
существующий объект; этот пакет с тремя объектами требует отдельной реализации
и проверки. Сериализатор свойств корня также не поддерживает создание объектов.

Запрос отправлен один раз после проверки текущего UUID версии хранилища и
исходной версии корня. Успех подтверждён повторным чтением сервера и штатной
выгрузкой, а не только отсутствием HTTP-ошибки. Ответ содержал код 6 с пустым
списком `unprocessed` и пустое поле `exc`, как в предыдущих успешных помещениях.
Исходные перехваченные запросы и файлы авторизации не включены в репозиторий.

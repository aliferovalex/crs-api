# Строковый реквизит справочника

`ПодготовитьСозданиеРеквизитаСправочника(Справочник, ИмяРеквизита, ДлинаСтроки = 100, ПутьPython = "python")`
возвращает `ПакетПомещенияОбъекта`. UUID нового реквизита доступен через
`Пакет.ИдентификаторРеквизита`. Поддержана переменная строка длины 1..1024.

```bsl
Справочник = Клиент.ПолучитьОписаниеОбъекта(UUIDСправочника);
Пакет = Клиент.ПодготовитьСозданиеРеквизитаСправочника(Справочник,
    "CRSAPI_TestAttribute", 100, "C:\Program Files\Python39\python.exe");
Клиент.ЗахватитьОбъект(Справочник);
Обновлённый = Клиент.ПоместитьСозданиеРеквизитаСправочника(Справочник,
    Пакет, "Новый строковый реквизит");
Клиент.ОтменитьЗахватОбъекта(Обновлённый);
```

Реквизит хранится внутри нативного тела справочника. Он не является самостоятельным
объектом хранилища: получать описание и захватывать его UUID отдельными методами
не нужно. Помещается справочник; метод возвращает его актуальное описание.
Проверяются версия объекта и хранилища, исходная версия, принадлежность захвата,
имя реквизита и длина строки. После помещения захват сохраняется.

Сериализатор добавляет запись в коллекцию реквизитов и UUID в набор признаков
справочника. Карта дочерних форм сохраняется; их данные не пересылаются.
Имена реквизитов проверяются на уникальность без учёта регистра. Можно добавлять
следующие реквизиты, сохраняя предыдущие. Имя — идентификатор 1С до 80 символов.
Остальные свойства нового реквизита имеют проверенные значения по умолчанию.

Ограничения: проверенная структура справочника; из отдельных дочерних объектов
поддержаны формы. Другие типы реквизитов, табличные части, изменение и удаление
реквизита пока не реализованы. Добавление реквизита само по себе не добавляет поле
на существующие формы. Генератор стандартных форм справочника допускает наличие
этих реквизитов, но выводит только код и наименование.

Профиль legacy, Python 3.9+ со стандартной библиотекой. Нативная проверка выполнена
на 8.5.1.1529; другие старые выпуски отдельно не проверялись. При подготовке пакета
Конфигуратор не запускается. Внутренние UUID версий формируются экспериментально.

В версии 15 создан `CRSAPI_TestAttribute` типа Строка/100/Variable. Нативная
CF-выгрузка, загрузка в отдельную базу и XML-выгрузка подтвердили реквизит. Обе формы
справочника и остальные объекты сохранились. Подготовка следующей формы после
добавления реквизита также проверена без помещения.

# Создание документа из XML

Методы `ПодготовитьСозданиеДокументаИзXML(Корень, XMLДокумента, ПутьPython)`
и `ПоместитьСозданиеДокумента(Пакет, Комментарий, ИдентификаторПодключения)`
создают простой документ в существующем HTTP-хранилище. Первый возвращает
`ПакетСозданияДокумента`, второй — актуальное описание созданного объекта.
UUID доступен в `Пакет.ИдентификаторОбъекта`.

Используется [профиль legacy](platform-compatibility.md): ветка 8.5.1 и более
ранние версии 8.x. Реальная проверка выполнена на 8.5.1.1529; применение к более
ранним версиям предполагает совместимость проверяемой структуры снимков.
Требуется Python 3.9+ со стандартной библиотекой. Конфигуратор не запускается
для построения или отправки пакета.

Передаётся текст отдельного файла `Documents/Имя.xml`. Имя должно отсутствовать
среди документов хранилища, UUID должен быть новым. Можно задать имя, синоним
и комментарий. Остальные явно указанные свойства должны иметь проверенные
значения по умолчанию: номер — строка длины 9, периодичность — `Nonperiodical`,
проведение и оперативное проведение — `Allow`. Движения по регистрам, новые
реквизиты, табличные части, формы, команды, макеты и содержимое модулей не
поддерживаются. `ChildObjects` должен отсутствовать или быть пустым.

```xml
<MetaDataObject xmlns="http://v8.1c.ru/8.3/MDClasses" version="2.21">
  <Document uuid="11111111-2222-4333-8444-555555555555">
    <Properties>
      <Name>XML_Document</Name>
      <Comment>Создан из XML</Comment>
    </Properties>
    <ChildObjects/>
  </Document>
</MetaDataObject>
```

```bsl
Корень = Клиент.ПолучитьОписаниеОбъекта(UUIDКорня);
Пакет = Клиент.ПодготовитьСозданиеДокументаИзXML(Корень,
    XMLДокумента, "C:\Program Files\Python39\python.exe");
Для Каждого Объект Из Пакет.СуществующиеОбъекты Цикл
    Клиент.ЗахватитьОбъект(Объект);
КонецЦикла;
Документ = Клиент.ПоместитьСозданиеДокумента(Пакет, "Документ из XML");
```

Если исходный объект уже захвачен текущим пользователем, повторный захват не
нужен. Все исходные объекты должны быть захвачены перед помещением. Метод
проверяет актуальность версии, владельца захвата, отсутствие нового UUID и
подтверждение созданной версии; после успеха сохраняет захваты. Для освобождения
используйте `ОтменитьЗахватОбъекта` со свежими описаниями исходных объектов и
нового документа. После ошибки отправки сначала проверяйте историю, не повторяйте
помещение автоматически.

Плоский контекст может содержать языки, константы, простые справочники и документы.
Вложенные и внешние данные отклоняются. Пять генерируемых типов документа читаются
из `InternalInfo`; без него создаются десять новых UUID. Проверки XML общие со
справочником (`flat_object_serializer.py`), а нативный шаблон, значения свойств,
позиции UUID типов и поля поиска находятся в `document_layout_851.json`.

В лаборатории `ManualClean8511529Lab` библиотека создала `CRSAPI_TestDocument`,
версия 6 → 7, и получила его обратно. Тело размером 1230 байт побайтно совпало
с записанным нативным пакетом, выгрузкой CF и результатом получения с сервера.
Захваты освобождены. Проверки включают построение графа, старый профиль,
сохранение UUID типов и отказы при неподдерживаемых свойствах или вложенных данных.

Сериализация экспериментальная: алгоритм нативного хеша версий не восстановлен,
генерация UUID/CRC версии остаётся прежней.

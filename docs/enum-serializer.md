# Создание перечисления из XML

Методы `ПодготовитьСозданиеПеречисленияИзXML(Корень, XMLПеречисления, ПутьPython)`
и `ПоместитьСозданиеПеречисления(Пакет, Комментарий, ИдентификаторПодключения)`
создают перечисление с его значениями. Первый возвращает `ПакетСозданияПеречисления`,
второй — актуальное описание созданного объекта. Новый UUID доступен через
`Пакет.ИдентификаторОбъекта`.

Используется [профиль legacy](platform-compatibility.md): ветка 8.5.1 и более ранние
версии 8.x с совместимой структурой данных. Реальная проверка выполнена на 8.5.1.1529.
Требуется Python 3.9+ со стандартной библиотекой. Для подготовки пакета и помещения
библиотека не запускает Конфигуратор.

Передаётся текст отдельного файла `Enums/Имя.xml`. Поддержаны имя, синоним и комментарий
перечисления; остальные явно указанные свойства должны иметь проверенные значения по
умолчанию. Для каждого `EnumValue` поддержаны UUID, имя, синоним, комментарий и цвет
`auto`. Формы, команды, макеты и прочие вложенные или внешние данные не принимаются.
Количество значений ограничено 1024; пустое перечисление допускается. Имена значений
проверяются на уникальность без учёта регистра, UUID всех элементов и типов — на
уникальность и пересечение с существующими данными.

```xml
<MetaDataObject xmlns="http://v8.1c.ru/8.3/MDClasses" version="2.21">
  <Enum uuid="11111111-2222-4333-8444-555555555555">
    <Properties><Name>XML_Enum</Name><Comment>Создано из XML</Comment></Properties>
    <ChildObjects>
      <EnumValue uuid="aaaaaaaa-aaaa-4aaa-8aaa-aaaaaaaaaaaa">
        <Properties><Name>First</Name></Properties>
      </EnumValue>
      <EnumValue uuid="bbbbbbbb-bbbb-4bbb-8bbb-bbbbbbbbbbbb">
        <Properties><Name>Second</Name></Properties>
      </EnumValue>
    </ChildObjects>
  </Enum>
</MetaDataObject>
```

UUID должны быть новыми, имя перечисления должно отсутствовать среди перечислений
хранилища. Три `InternalInfo/GeneratedType` (`Ref`, `Manager`, `List`) читаются из XML;
без этого раздела генерируются шесть новых UUID типов. Значения хранятся внутри
нативного тела перечисления в порядке XML. Метод создания не возвращает их как
отдельные объекты хранилища и не реализует отдельный захват или изменение значения.

```bsl
Корень = Клиент.ПолучитьОписаниеОбъекта(UUIDКорня);
Пакет = Клиент.ПодготовитьСозданиеПеречисленияИзXML(Корень,
    XMLПеречисления, "C:\Program Files\Python39\python.exe");
Для Каждого Объект Из Пакет.СуществующиеОбъекты Цикл
    Клиент.ЗахватитьОбъект(Объект);
КонецЦикла;
Перечисление = Клиент.ПоместитьСозданиеПеречисления(Пакет, "Перечисление из XML");
```

Все исходные объекты должны быть захвачены текущим пользователем; уже захваченный
объект повторно захватывать не нужно. После помещения захваты сохраняются. Освободите
их через `ОтменитьЗахватОбъекта`, получив свежие описания исходных объектов и нового
перечисления. После ошибки отправки проверяйте историю перед повтором.

Контекст поддерживает языки, константы, простые справочники, документы и перечисления.
Исключение для вложенности сделано только для встроенных значений перечисления;
остальные вложенные и внешние данные по-прежнему отклоняются. Нативный шаблон,
свойства и позиции UUID типов вынесены в `enum_layout_851.json`; XML обрабатывает
общий `flat_object_serializer.py` через обёртку `enum_serializer.py`.

## Проверка без ручных действий

Перечисление `CRSAPI_TestEnum` со значениями `First` и `Second` создано из XML
штатным Конфигуратором через `/LoadConfigFromFiles` в отдельной неподключённой
лабораторной базе. Затем получены XML и CF, по ним восстановлен шаблон сериализации.
Записанный HTTP-запрос помещения для этого опыта не использовался.

Библиотека создала объект в `ManualClean8511529Lab`, версия 7 → 8, получила его и
освободила захваты. Тело 1032 байта совпало побайтно с нативной CF и результатом
получения с сервера. Дополнительно штатный Конфигуратор выгрузил CF прямо из
хранилища через `/ConfigurationRepositoryDumpCfg`: перечисление с обоими значениями
совпало с исходной нативной структурой. Повторное обновление в GUI не проверялось.

Алгоритм нативного хеша версий не восстановлен; сериализация остаётся экспериментальной.

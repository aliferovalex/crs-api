# CRS API

Библиотека OneScript для взаимодействия с сервером хранилищ конфигураций 1С по
HTTP и TCP. Включает управление пользователями, получение объектов, захват и отмену
захвата, помещение нативных пакетов и подготовку изменений XML-выгрузки
Конфигуратора через внешний компилятор ibcmd-rs. Собственного XML-сериализатора нет.

**[Возможности, ограничения и дальнейшие задачи](docs/status.md)** — единое
описание текущего состояния, совместимости, зависимостей и порядка работы.
Основная проверенная платформа — 8.5.1.1529. Сериализация любых изменений
произвольной конфигурации пока не завершена.

Для ИИ-агентов и автоматизации доступны [JSON CLI](docs/status.md#json-cli),
[MCP-сервер через stdio](docs/status.md#mcp-сервер) и проектный
[навык 1c-repository](skills/1c-repository/SKILL.md).

**[Установка MCP для пользователя и агента](docs/mcp-install.md)** — зависимости,
настройка профиля и пароля, подключение к Codex и проверка прямых вызовов.

Для больших конфигураций доступны [лимиты профиля и файловая обработка ответов](docs/status.md#размеры-и-защитные-лимиты):
первоначальная загрузка кэша и источник подготовки не передают общий контейнер через JSON/base64.

Проект основан на [otymko/crs-api](https://github.com/otymko/crs-api).
Новые возможности относятся к исходникам этого форка; опубликованный пакет
`opm` может иметь другое покрытие.

Для TCP веб-публикация не нужна:

```bsl
Клиент = Новый КлиентХранилища("tcp://localhost:1542/MyRepo", "8.5.1.1529");
Клиент.Подключиться("Администратор", "");
```

Можно также передать адрес сервера без имени хранилища, указав имя третьим
параметром `Подключиться`. Остальные методы одинаковы для HTTP и TCP.

# CRS API

Для поиска кода и объектов в хранилище 1С, чтения содержимого, локальной подготовки
изменений и работы с пользователями используй
[skills/1c-repository/SKILL.md](skills/1c-repository/SKILL.md).

Общий интерфейс — `python tools/crs.py`; формат JSON и ограничения находятся
в [docs/status.md](docs/status.md#json-cli). CLI использует существующую библиотеку.
MCP-адаптер `python tools/crs_mcp.py --config CONFIG` предоставляет те же операции
как инструменты; подключение и ограничения — в разделе «MCP-сервер» документации.
Порядок установки и проверки для пользователя и агента:
[docs/mcp-install.md](docs/mcp-install.md).

Изменения самой библиотеки проверяй локальными тестами. Проверки интеграции с
записью выполняй на изолированной локальной копии хранилища; разрешение менять
код проекта не означает разрешения менять пользователей общего хранилища.
